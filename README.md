# affiliate-agent-portal

Agent portal for the LinkChinaMed affiliate program.

- Domain: `https://agent.linkchinamed.com`
- Stack: Next.js 16 + next-intl + Supabase auth + Turnstile
- Backend: shared `affiliate-service` Express API at `https://api.linkchinamed.com`

See `docs/superpowers/specs/2026-08-10-agent-portal-split-design.md` for design.
